# rx_keywords.txt - salts that make a medicine "prescription only" (rx_required = true)
#
# HOW IT WORKS
#   * One keyword per line, case-insensitive. Lines starting with # are comments.
#   * A keyword matches when it appears at the START OF A WORD in salt_composition.
#     So "cef" matches Cefixime, Ceftriaxone, Cefpodoxime... and "amlodipine"
#     matches "Amlodipine + Telmisartan".
#   * A line like  form:injection  marks EVERY medicine in that dosage form as Rx.
#     Delete that line if you don't want it.
#
# Left OFF on purpose (OTC vs Rx is a judgement call): paracetamol, ibuprofen,
# diclofenac, aceclofenac, nimesulide, cetirizine, levocetirizine, clotrimazole,
# ketoconazole. Add any of them above if your project treats them as Rx.
#
# THIS LIST IS A DEMO HEURISTIC. Have a pharmacist review it before real use.
