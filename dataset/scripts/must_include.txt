#   * One brand per line, case-insensitive, hyphens and spaces treated the same.
#   * A line matches brand names that START with it, as whole words:
#       "Dolo 650"  matches "Dolo 650 Tablet" and "Dolo 650mg Tablet"
#       "Crocin"    matches "Crocin Advance Tablet", "Crocin 1000mg Tablet" ...
#       "Dolo"      does NOT match "Dolonex" (it must end at a word boundary)
#     To pick one product only, write more of the name ("Crocin Advance").
#   * The script prints any line that matched nothing, so you can fix typos.
#

# ORS and Ayurvedic brands (Shelcal, Digene, Electral, Liv 52 ...) are NOT in it.
# They are listed at the bottom so the report reminds you to add them by hand.
